# Inspiracje – Aplikacja do szybkiego liczenia opłacalności

**Projekt:**  
Aplikacja do szybkiego liczenia opłacalności pomysłów/ofert dla mikrofirm, freelancerów i startupów.

---

## 1. Inspiracje (słowa, skojarzenia, pomysły)

- opłacalność / rentowność / ROI  
- „czy to się spina?”  
- szybkie decyzje biznesowe  
- prostota zamiast Excela  
- kalkulator + symulacje „co jeśli…”  
- marża, narzut, próg rentowności  
- wycena oferty / pricing  
- kontrola kosztów stałych i zmiennych  
- minimalny przychód / minimalna cena  
- scenariusze: optymistyczny / realistyczny / pesymistyczny  
- mikroprzedsiębiorca, freelancer, startup (MVP)  
- przejrzystość, czytelne wnioski, rekomendacje  
- „dashboard” w 1 ekranie  
- oszczędność czasu, mniej stresu, pewniejsze decyzje  

---

## 2. Krótka lista elementów projektu (moduły / funkcje)

- ekran startowy: wybór typu kalkulacji  
- kalkulator kosztów  
  - stałe / zmienne  
  - jednorazowe / cykliczne  
- kalkulator przychodów (cena, ilość, częstotliwość)  
- kalkulator marży / narzutu  
- wynik: **zysk / strata + rentowność**  
- symulacje „co jeśli” (zmiana ceny, kosztów, wolumenu)  
- scenariusze (3 warianty porównawcze)  
- podsumowanie decyzji:  
  - *opłaca się*  
  - *nie opłaca się*  
  - *zależy od…*  
- zapis projektów / ofert (historia kalkulacji)  
- eksport (PDF / CSV) – opcjonalnie  
- proste porady / tooltipy  
  - definicje: **marża vs narzut**

---

## 3. Wstępne dane wejściowe

### 3.1 Kategorie (obszary kosztów i przychodów)

#### Koszty stałe
- ZUS / księgowość / podatki (orientacyjnie)  
- narzędzia i subskrypcje (SaaS)  
- biuro / cowork / media  
- marketing stały (abonamenty)  

#### Koszty zmienne
- materiały / produkcja  
- podwykonawcy / prowizje  
- dostawa / logistyka  
- opłaty płatnicze (bramki, prowizje)  
- czas pracy (stawka godzinowa) – jako koszt własny  

#### Przychody
- sprzedaż usług (pakiety, godziny)  
- sprzedaż produktów (cena × ilość)  
- abonamenty / subskrypcje  
- jednorazowe wdrożenia / projekty  

---

### 3.2 Lista funkcji (MVP vs później)

#### MVP
- dodaj koszty i przychody  
- policz marżę / zysk / próg rentowności  
- symulacja 1–2 parametrów (np. cena, ilość)  
- proste wnioski i podsumowanie  

#### Później
- scenariusze 3-wariantowe + porównanie  
- zapisywanie projektów i wersjonowanie  
- eksport PDF / CSV  
- szablony branżowe  
  - usługi  
  - e-commerce  
  - konsulting  
- rekomendacje cenowe  
  - np. minimalna cena przy X marży  
- integracje (np. fakturowanie) – opcjonalnie  

---

## 4. Źródła pomysłu

- własna potrzeba: szybka ocena, czy oferta / pomysł się opłaca bez żmudnego Excela  
- obserwacja rynku: mikrofirmy i freelancerzy często nie liczą pełnych kosztów  
  - zwłaszcza kosztów stałych i czasu pracy  
- rozmowy z innymi przedsiębiorcami:  
  - „nie wiem jak wycenić”  
  - „czy to ma sens finansowo”  
- przypadek: potrzeba policzenia opłacalności konkretnej oferty / projektu „na szybko”  
- inspiracja narzędziami:  
  - arkusze kalkulacyjne  
  - kalkulatory marży  
  - proste fintechowe dashboardy  
  - **jedna, prosta aplikacja zamiast wielu narzędzi**
